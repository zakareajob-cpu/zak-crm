# Space Cat Jump (Android - First Version)

A colorful, kid-friendly mini game where a tiny cat jumps from one planet to the next in space.

## Gameplay
- Tap anywhere on the screen to make the cat jump to the next planet.
- Score increases with each jump distance.
- Reach the last planet to win, then tap again to restart.

## Tech
- Kotlin
- Jetpack Compose Canvas
- Android SDK 34

## Run
1. Open the `android-space-cat` folder in Android Studio.
2. Let Gradle sync.
3. Run on an emulator or Android device (API 26+).
